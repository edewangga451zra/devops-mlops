AmbaTo

Sistem Informasi Order Fotografi — photo-client-web. (Amba Studio Foto)

Web pemesanan jasa foto: klien pilih paket, isi nama + WA + tanggal sesi, dapat ID order + kode. Admin konfirmasi bayar, jadwalkan sesi, siapkan galeri, unggah foto, aktifkan galeri 7 hari. Klien buka galeri, pilih foto sesuai kuota paket, kirim pilihan. Editor kerjakan foto terpilih, unggah hasil edit. Klien unduh hasil bila status selesai.

Paket: Hemat (1 foto, Rp400rb), Standar (3 foto, Rp750rb), Premium (10 foto, Rp1jt), Komplit (semua foto, Rp1,5jt).

Peran: klien (tanpa login, pakai ID + kode), admin (bayar, jadwal, galeri, WA), editor (progres + unggah hasil).

Panel admin Order masuk bagi 4: Orang-1 fondasi + filter + daftar, Orang-2 kartu + bayar + jadwal + editor, Orang-3 galeri + unggah + timer 7 hari, Orang-4 kirim WA gateway + chat manual.

Fitur: date picker tolak tanggal lewat + bentrok, countdown Sisa hari/jam/menit, perpanjang +7 hari, reset akses, template WA tagihan/jadwal/galeri/pengingat/hasil.

Teknologi: Node.js + Express + express-session, store JSON data/db.json, upload multer ke uploads/, frontend HTML + CSS + JS vanilla, font Inter + JetBrains Mono.
